## Question GATE-1996-OS-01: Operating Systems - Effective Memory Access Time with Multi-Level Paging
**Topic**: Operating Systems / Memory Management & Paging
**Question**:
Consider a computer system with a 2-level paging scheme. The translation lookaside buffer (TLB) hit ratio is 0.95. The access time of the TLB is 20 ns, and the main memory access time is 100 ns. What is the effective memory access time (EMAT) of the system?
(A) 120 ns
(B) 125 ns
(C) 130 ns
(D) 135 ns

**Key Technical Concepts**: Effective Memory Access Time (EMAT), TLB hit ratio, 2-level paging, page table lookup overhead, main memory access time.

**Step-by-Step Solution & Derivation**:
- In a 2-level paging scheme, resolving a logical address without TLB requires:
  1. Accessing the first-level page table in main memory (100 ns).
  2. Accessing the second-level page table in main memory (100 ns).
  3. Accessing the actual target data frame in main memory (100 ns).
  Total memory accesses on TLB miss = $2 + 1 = 3$ accesses.
- On a TLB hit:
  Time taken = $T_{\text{TLB}} + T_{\text{mem}} = 20\text{ ns} + 100\text{ ns} = 120\text{ ns}$.
- On a TLB miss:
  Time taken = $T_{\text{TLB}} + 2 \times T_{\text{mem}} + T_{\text{mem}} = 20\text{ ns} + 300\text{ ns} = 320\text{ ns}$.
- Formula for EMAT:
  $$\text{EMAT} = h \times (T_{\text{TLB}} + T_{\text{mem}}) + (1 - h) \times (T_{\text{TLB}} + (k + 1) \times T_{\text{mem}})$$
  where $h = 0.95$, $k = 2$ (levels of paging), $T_{\text{TLB}} = 20\text{ ns}$, $T_{\text{mem}} = 100\text{ ns}$.
- Calculation:
  $$\text{EMAT} = 0.95 \times (20 + 100) + (1 - 0.95) \times (20 + 3 \times 100)$$
  $$\text{EMAT} = 0.95 \times 120 + 0.05 \times 320 = 114 + 16 = 130\text{ ns}$$

**Correct Answer**: (C) 130 ns

## Question GATE-2004-OS-02: Operating Systems - SRTF CPU Scheduling & Waiting Time
**Topic**: Operating Systems / CPU Scheduling
**Question**:
Consider the following set of processes with arrival time and CPU burst times given in milliseconds:
- Process P1: Arrival Time = 0 ms, Burst Time = 8 ms
- Process P2: Arrival Time = 1 ms, Burst Time = 4 ms
- Process P3: Arrival Time = 2 ms, Burst Time = 9 ms
- Process P4: Arrival Time = 3 ms, Burst Time = 5 ms
What is the average waiting time for these processes under the Shortest Remaining Time First (SRTF) preemptive scheduling algorithm?
(A) 5.5 ms
(B) 6.5 ms
(C) 7.0 ms
(D) 7.5 ms

**Key Technical Concepts**: Shortest Remaining Time First (SRTF), preemptive scheduling, Gantt chart construction, completion time, turnaround time, waiting time.

**Step-by-Step Solution & Derivation**:
- Gantt Chart Execution:
  - $t = 0$: Only P1 is present. P1 executes for 1 ms (Remaining P1 = 7 ms).
  - $t = 1$: P2 arrives (Burst = 4 ms). Since Remaining(P2)=4 < Remaining(P1)=7, P1 is preempted by P2.
  - $t = 1 \text{ to } 5$: P2 runs to completion. At $t = 5$, P2 finishes.
  - At $t = 5$, available ready processes are: P1 (rem: 7), P3 (arr: 2, rem: 9), P4 (arr: 3, rem: 5).
  - Smallest remaining time is P4 (5 ms). P4 executes from $t = 5 \text{ to } 10$. P4 finishes at $t = 10$.
  - Next smallest is P1 (7 ms). P1 executes from $t = 10 \text{ to } 17$. P1 finishes at $t = 17$.
  - Finally, P3 (9 ms) executes from $t = 17 \text{ to } 26$. P3 finishes at $t = 26$.
- Metrics Table:
  - P1: Completion Time = 17, Turnaround Time = $17 - 0 = 17$, Waiting Time = $17 - 8 = 9\text{ ms}$.
  - P2: Completion Time = 5, Turnaround Time = $5 - 1 = 4$, Waiting Time = $4 - 4 = 0\text{ ms}$.
  - P3: Completion Time = 26, Turnaround Time = $26 - 2 = 24$, Waiting Time = $24 - 9 = 15\text{ ms}$.
  - P4: Completion Time = 10, Turnaround Time = $10 - 3 = 7$, Waiting Time = $7 - 5 = 2\text{ ms}$.
- Average Waiting Time:
  $$\text{Avg WT} = \frac{9 + 0 + 15 + 2}{4} = \frac{26}{4} = 6.5\text{ ms}$$

**Correct Answer**: (B) 6.5 ms

## Question GATE-2015-OS-03: Operating Systems - Banker's Algorithm Safe Sequence & Allocation
**Topic**: Operating Systems / Deadlocks & Banker's Algorithm
**Question**:
A system has 3 resource types (A, B, C) with total instances $(10, 5, 7)$. There are 5 processes (P0, P1, P2, P3, P4).
Current Allocation Matrix:
- P0: (0, 1, 0)
- P1: (2, 0, 0)
- P2: (3, 0, 2)
- P3: (2, 1, 1)
- P4: (0, 0, 2)
Max Demand Matrix:
- P0: (7, 5, 3)
- P1: (3, 2, 2)
- P2: (9, 0, 2)
- P3: (2, 2, 2)
- P4: (4, 3, 3)
Which of the following represents a valid Safe Execution Sequence for the system?
(A) < P1, P3, P4, P0, P2 >
(B) < P0, P1, P2, P3, P4 >
(C) < P2, P1, P3, P4, P0 >
(D) No safe sequence exists (Deadlock)

**Key Technical Concepts**: Banker's Algorithm, Safety Algorithm, Need Matrix calculation, Available Resource Vector, Safe Sequence.

**Step-by-Step Solution & Derivation**:
1. Calculate Total Allocated Resources:
   $$\text{Total Allocated} = (0+2+3+2+0, 1+0+0+1+0, 0+0+2+1+2) = (7, 2, 5)$$
2. Available Vector:
   $$\text{Available} = \text{Total Instances} - \text{Total Allocated} = (10, 5, 7) - (7, 2, 5) = (3, 3, 2)$$
3. Compute Need Matrix ($\text{Need} = \text{Max} - \text{Allocation}$):
   - $\text{Need}(P0) = (7, 5, 3) - (0, 1, 0) = (7, 4, 3)$
   - $\text{Need}(P1) = (3, 2, 2) - (2, 0, 0) = (1, 2, 2)$
   - $\text{Need}(P2) = (9, 0, 2) - (3, 0, 2) = (6, 0, 0)$
   - $\text{Need}(P3) = (2, 2, 2) - (2, 1, 1) = (0, 1, 1)$
   - $\text{Need}(P4) = (4, 3, 3) - (0, 0, 2) = (4, 3, 1)$
4. Check Process Execution Feasibility:
   - Available = $(3, 3, 2)$.
   - Check P1: $\text{Need}(P1) = (1, 2, 2) \le (3, 3, 2)$ $\implies$ **True**.
     P1 executes and releases allocation $(2, 0, 0)$:
     $$\text{New Available} = (3, 3, 2) + (2, 0, 0) = (5, 3, 2)$$
   - Check P3: $\text{Need}(P3) = (0, 1, 1) \le (5, 3, 2)$ $\implies$ **True**.
     P3 executes and releases allocation $(2, 1, 1)$:
     $$\text{New Available} = (5, 3, 2) + (2, 1, 1) = (7, 4, 3)$$
   - Check P4: $\text{Need}(P4) = (4, 3, 1) \le (7, 4, 3)$ $\implies$ **True**.
     P4 executes and releases allocation $(0, 0, 2)$:
     $$\text{New Available} = (7, 4, 3) + (0, 0, 2) = (7, 4, 5)$$
   - Check P0: $\text{Need}(P0) = (7, 4, 3) \le (7, 4, 5)$ $\implies$ **True**.
     P0 executes and releases allocation $(0, 1, 0)$:
     $$\text{New Available} = (7, 4, 5) + (0, 1, 0) = (7, 5, 5)$$
   - Check P2: $\text{Need}(P2) = (6, 0, 0) \le (7, 5, 5)$ $\implies$ **True**.
     P2 finishes.
- The valid safe sequence is: $< P1, P3, P4, P0, P2 >$.

**Correct Answer**: (A) < P1, P3, P4, P0, P2 >

## Question GATE-2021-OS-04: Operating Systems - Belady's Anomaly in FIFO Page Replacement
**Topic**: Operating Systems / Virtual Memory & Page Replacement
**Question**:
Which of the following page replacement algorithms CANNOT exhibit Belady's Anomaly (where increasing the number of page frames results in an increased number of page faults for a reference string)?
(A) First-In-First-Out (FIFO)
(B) Least Recently Used (LRU)
(C) Second-Chance / Clock Algorithm
(D) Random Page Replacement

**Key Technical Concepts**: Belady's Anomaly, Stack Algorithms, Inclusion Property, Least Recently Used (LRU), Optimal Page Replacement (OPT).

**Step-by-Step Solution & Derivation**:
- **Belady's Anomaly Definition**: Anomaly in page replacement where allocating more physical memory frames increases the total number of page faults.
- **Stack Algorithms Theorem**: An algorithm is a stack algorithm if the set of pages in memory for $n$ frames is always a proper subset of the set of pages in memory for $n+1$ frames:
  $$S(n) \subseteq S(n+1)$$
- Stack algorithms strictly satisfy the **Inclusion Property**, making Belady's Anomaly mathematically impossible.
- **Stack Algorithms**: LRU (Least Recently Used), LFU (Least Frequently Used), OPT/MIN (Optimal).
- Non-stack algorithms such as FIFO, Second-Chance, and Random replacement do NOT satisfy the inclusion property and CAN suffer from Belady's anomaly.

**Correct Answer**: (B) Least Recently Used (LRU)

## Question GATE-2024-OS-05: Operating Systems - Counting Semaphores Value Range
**Topic**: Operating Systems / Process Synchronization & Semaphores
**Question**:
A counting semaphore $S$ is initialized to 10. Then, 15 $P$ (wait) operations and 7 $V$ (signal) operations are performed on $S$ in arbitrary order. What is the final value of the counting semaphore $S$?
(A) 0
(B) 2
(C) -2
(D) 5

**Key Technical Concepts**: Counting Semaphore, $P$ operation (`wait` decrement), $V$ operation (`signal` increment), concurrency synchronization invariant.

**Step-by-Step Solution & Derivation**:
- Counting semaphore semantics:
  - Initialization: $S = S_0 = 10$.
  - $P(S)$ operation: Decrements the semaphore value by 1 ($S \leftarrow S - 1$).
  - $V(S)$ operation: Increments the semaphore value by 1 ($S \leftarrow S + 1$).
- Invariant equation:
  $$S_{\text{final}} = S_{\text{initial}} - N_P + N_V$$
  where $N_P = 15$, $N_V = 7$, $S_{\text{initial}} = 10$.
- Calculation:
  $$S_{\text{final}} = 10 - 15 + 7 = 17 - 15 = 2$$
- Therefore, the final value of semaphore $S$ is 2.

**Correct Answer**: (B) 2

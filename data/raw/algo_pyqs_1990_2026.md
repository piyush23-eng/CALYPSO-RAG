## Question GATE-2003-ALGO-01: Algorithms - Floyd's Linear Time Max-Heap Build Derivation
**Topic**: Algorithms / Heap Data Structure & Analysis
**Question**:
What is the worst-case asymptotic time complexity of building a binary max-heap of $n$ elements from an unsorted array using Floyd's bottom-up `BUILD-HEAP` algorithm?
(A) $O(n \log n)$
(B) $O(n)$
(C) $O(\log n)$
(D) $O(n^2)$

**Key Technical Concepts**: Floyd's `BUILD-MAX-HEAP`, heapify operations, tree height summations, Taylor series expansion $\sum_{h=0}^{\infty} \frac{h}{2^h} = 2$.

**Step-by-Step Solution & Derivation**:
- In Floyd's algorithm, `MAX-HEAPIFY` is invoked bottom-up on nodes from index $\lfloor n/2 \rfloor$ down to $1$.
- In a complete binary tree of $n$ elements:
  - Height of the tree: $h_{\max} = \lfloor \log_2 n \rfloor$.
  - Number of nodes at height $h$: at most $\lceil \frac{n}{2^{h+1}} \rceil$.
  - Cost of running `MAX-HEAPIFY` on a node at height $h$: $O(h)$ swaps.
- Total time complexity summation:
  $$T(n) = \sum_{h=0}^{\lfloor \log_2 n \rfloor} \lceil \frac{n}{2^{h+1}} \rceil O(h) = O\left( n \sum_{h=0}^{\infty} \frac{h}{2^h} \right)$$
- Using the standard mathematical identity for the arithmetico-geometric series:
  $$\sum_{h=0}^{\infty} h x^h = \frac{x}{(1 - x)^2} \quad \text{for } |x| < 1$$
  Setting $x = 1/2$:
  $$\sum_{h=0}^{\infty} \frac{h}{2^h} = \frac{1/2}{(1 - 1/2)^2} = \frac{1/2}{1/4} = 2$$
- Therefore:
  $$T(n) = O(n \times 2) = O(n)$$
- Floyd's bottom-up build runs in strictly linear time $O(n)$, whereas repeated top-down insertion requires $O(n \log n)$.

**Correct Answer**: (B) $O(n)$

## Question GATE-2011-ALGO-02: Algorithms - Master Theorem Recurrence Resolution
**Topic**: Algorithms / Asymptotic Analysis & Recurrences
**Question**:
Consider the recurrence relation:
$$T(n) = 4 T(n/2) + n^2 \log n$$
with base condition $T(1) = \Theta(1)$. What is the asymptotic tight bound $\Theta(T(n))$?
(A) $\Theta(n^2)$
(B) $\Theta(n^2 \log n)$
(C) $\Theta(n^2 \log^2 n)$
(D) $\Theta(n^{\log_2 4})$

**Key Technical Concepts**: Master Theorem for Divide-and-Conquer Recurrences, $T(n) = a T(n/b) + f(n)$, critical exponent $\log_b a$, Case 2 with poly-logarithmic factor $f(n) = \Theta(n^{\log_b a} \log^k n)$.

**Step-by-Step Solution & Derivation**:
1. Identify Master Theorem parameters:
   - $a = 4$ (subproblems per step)
   - $b = 2$ (problem size divisor)
   - $f(n) = n^2 \log n$
2. Compute the critical polynomial term:
   $$n^{\log_b a} = n^{\log_2 4} = n^2$$
3. Compare $f(n)$ with $n^{\log_b a}$:
   $$f(n) = n^2 \log^1 n = \Theta(n^{\log_b a} \log^k n) \quad \text{with } k = 1$$
4. Apply Master Theorem Extended Case 2:
   If $f(n) = \Theta(n^{\log_b a} \log^k n)$ where $k \ge 0$, then:
   $$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$$
5. Substitute $k = 1$:
   $$T(n) = \Theta(n^2 \log^{1+1} n) = \Theta(n^2 \log^2 n)$$

**Correct Answer**: (C) $\Theta(n^2 \log^2 n)$

## Question GATE-2016-ALGO-03: Algorithms - Dijkstra vs Bellman-Ford Shortest Path
**Topic**: Algorithms / Graph Algorithms
**Question**:
Which of the following statements is TRUE regarding Single-Source Shortest Path (SSSP) algorithms on directed graphs?
(A) Dijkstra's algorithm always finds the shortest path in graphs with negative weight edges, provided there are no negative cycles.
(B) Bellman-Ford algorithm can detect the presence of negative-weight cycles reachable from the source vertex in $O(V \cdot E)$ time.
(C) Floyd-Warshall algorithm cannot be used on graphs with negative edge weights.
(D) Dijkstra's algorithm with a Fibonacci heap runs in $O(V^2)$ time.

**Key Technical Concepts**: Dijkstra's Greedy SSSP, non-negative edge weight precondition, Bellman-Ford Dynamic Programming, negative cycle detection, relaxation invariant.

**Step-by-Step Solution & Derivation**:
- **Dijkstra's Algorithm**: Relies on a greedy invariant that once a vertex $u$ is extracted from the priority queue (marked settled), its distance estimate $d[u]$ is optimal. Negative edge weights violate this non-decreasing subpath property, causing Dijkstra to produce incorrect shortest distances.
- **Bellman-Ford Algorithm**: Relaxes all $|E|$ edges $|V| - 1$ times. If a further relaxation in the $|V|$-th iteration reduces any distance estimate ($d[v] > d[u] + w(u, v)$), it conclusively indicates the presence of a reachable negative-weight cycle.
- Time complexity of Bellman-Ford is $O(V \cdot E)$.

**Correct Answer**: (B) Bellman-Ford algorithm can detect the presence of negative-weight cycles reachable from the source vertex in $O(V \cdot E)$ time.

## Question GATE-2022-ALGO-04: Algorithms - 0/1 Knapsack Dynamic Programming
**Topic**: Algorithms / Dynamic Programming
**Question**:
For the 0/1 Knapsack problem with $n$ items and capacity $W$, what is the space and time complexity of the standard Dynamic Programming solution?
(A) Time: $O(n W)$, Space: $O(n W)$ (reducible to $O(W)$)
(B) Time: $O(2^n)$, Space: $O(n)$
(C) Time: $O(n \log n)$, Space: $O(1)$
(D) Time: $O(W^2)$, Space: $O(n)$

**Key Technical Concepts**: 0/1 Knapsack, Pseudo-polynomial time, optimal substructure, 1D array space optimization.

**Step-by-Step Solution & Derivation**:
- Let $dp[i][w]$ denote the maximum value attainable using a subset of the first $i$ items with weight constraint $w$.
- Recurrence Relation:
  $$dp[i][w] = \begin{cases} dp[i-1][w] & \text{if } w_i > w \\ \max(dp[i-1][w], dp[i-1][w - w_i] + v_i) & \text{if } w_i \le w \end{cases}$$
- Table dimensions are $(n+1) \times (W+1)$, taking $O(n W)$ time and $O(n W)$ space.
- Since $dp[i][w]$ only depends on the previous row $dp[i-1]$, space can be optimized to a single 1D array of size $O(W)$ by traversing right-to-left ($w = W \text{ down to } w_i$).

**Correct Answer**: (A) Time: $O(n W)$, Space: $O(n W)$ (reducible to $O(W)$)
